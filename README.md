# Sigillo

App locale di sistemo.ai che **pseudonimizza** i documenti prima che escano dal tuo computer:
nomi, codici fiscali, IBAN e indirizzi diventano segnaposto (`[FULLNAME_1]`) e tornano al loro
posto quando serve. Tutto gira sul tuo Mac, Windows o Linux, senza cloud.

Pagina: https://sistemo.ai/sigillo

> **Non è anonimizzazione garantita.** È pseudonimizzazione reversibile: controlla sempre il
> risultato prima di condividerlo. Le metriche (F1 0,989) le dichiara l'autore del modello.
